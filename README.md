## Automatic updates

GitHub Actions checks the upstream Dashboard Icons index every day at 04:17 Asia/Shanghai.
It regenerates both Loon iconsets and commits only when generated files change.

Manual update:
Actions → Update Dashboard Icons for Loon → Run workflow

## Files

- `.github/workflows/update-icons.yml` — scheduled/manual update workflow
- `scripts/generate_icons.py` — converts upstream PNG index to Loon iconset JSON
- `scripts/selected-icons.txt` — curated icon names
- `IconSet/Dashboard-Icons-Loon-Selected.json` — curated set
- `IconSet/Dashboard-Icons-Loon-Full.json` — full set
